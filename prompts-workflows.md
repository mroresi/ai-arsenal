# Prompts and workflows

Honest framing first: most prompt packs are hype. The research rejected the "genius tutor" prompts, the 55 cheat codes, and the Hormozi Brain (real repo, wrong life) as not worth implementing. This page keeps only what survives scrutiny.

- [dair-ai/Prompt-Engineering-Guide](https://github.com/dair-ai/Prompt-Engineering-Guide) - the reference book: techniques from basics to advanced (CoT, ToT, ReAct, RAG), with examples. Look up a technique, do not memorize the list.
- [danielmiessler/fabric](https://github.com/danielmiessler/fabric) - prompts organized as reusable CLI patterns (summarize, analyze, extract). Run and chain them; this is the one "prompt pack" shaped like a tool instead of a listicle.
- [f/prompts.chat](https://github.com/f/prompts.chat) - the successor to Awesome ChatGPT Prompts. Large prompt library; steal the pattern, rewrite, do not copy verbatim.
- [HandlyTech prompts](https://handlytech.com/prompts) - 111 AI image/video prompts (60 image, 51 video) from creator Ayham Joukhadar. The value is the pattern grammar: identity ref + scene ref for "put yourself in it" edits, camera-move vocabulary for image-to-video. Link it, do not republish the prompt texts, they are the creator's content.
- [HandlyTech free AI tools directory](https://handlytech.com/tools) - 221 free AI web tools, filterable by category. A discovery shortlist for the manual steps of a pipeline (voice, music, upscaling); most are web UIs, not APIs.
- [HandlyTech free editing tools](https://handlytech.com/free-tools) - 69 in-browser, no-signup tools (background removal, upscaling, reel safe zones, captions to SRT). Use for finishing; replicate the same ops inside n8n with the Edit Image node or ffmpeg.
- n8n creator pipelines (researched 2026-10-09): the OpenAI node's Edit Image accepts up to 16 reference images, which is exactly the two-image remix pattern. Video via fal.ai, Runway, or Veo through HTTP Request with Wait-node polling. Publishing is the weak link: no native Instagram/TikTok nodes, use community nodes or a scheduler service. Full image-to-video-to-publish pipeline runs about $0.30-$3.50 per finished post. Patterns to automate, not prompt texts: (a) scheduled prompt-of-the-day generator with Telegram approval, (b) product photo in, UGC lifestyle scenes out, resized per platform, (c) still image to short video, (d) batch variation generator for A/B tests.
