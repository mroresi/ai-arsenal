# Awesome lists

The meta-list. Check these before building anything; someone has usually already curated the space.

## Skills

- [4riel/awesome-claude-skills](https://github.com/4riel/awesome-claude-skills) - curated Claude skills collection.
- [VoltAgent/awesome-agent-skills](https://github.com/VoltAgent/awesome-agent-skills) - plug-and-play skills for Claude, Cursor, and similar agents.
- [collectifweb/claude-skills](https://github.com/collectifweb/claude-skills) - community Claude skill picks.
- [Art-of-Technology/skills](https://github.com/Art-of-Technology/skills) - technology-focused skill collection.

## Agents

- [jmagly/awesome-agent-almanac-aiwg](https://github.com/jmagly/awesome-agent-almanac-aiwg) - agents, agent tools, MCP servers, and agentic tech in one auto-generated list.
- [usejina/awesome-engineering-agents](https://github.com/usejina/awesome-engineering-agents) - AI engineering agents across IDEs, codegen, testing, DevOps, and docs.

## Local LLM

- [marlburrow/awesome-local-ai-2](https://github.com/marlburrow/awesome-local-ai-2) - local-first AI tools, frameworks, and self-hosted solutions; inference engines, models, RAG, voice, hardware.
- [townie/awesome-os-llm](https://github.com/townie/awesome-os-llm) - open-source LLM serving engines, local apps, and front ends, with honest notes on what each entry actually is.

## Self-hosted

- [internetcityhd/awesome-selfhosted](https://github.com/internetcityhd/awesome-selfhosted) - the big one: free software network services and web apps you can host yourself.
- [shakelv/oar-awesome-self-hosted-agents](https://github.com/shakelv/oar-awesome-self-hosted-agents) - tools and frameworks for running AI agents fully self-hosted, no vendor lock-in.
- [marlburrow/awesome-oss-ai-alternatives](https://github.com/marlburrow/awesome-oss-ai-alternatives) - open-source replacements for paid AI tools (ChatGPT, Figma, Cursor, Midjourney, and more), self-hostable.
